# Contributing to ORIGO

Thank you for your interest in ORIGO.

ORIGO is an evolving project. Contributions should help improve its clarity,
reliability, usability, or documented direction while respecting the scope of
the current implementation.

## Before contributing

- Read the README and relevant documentation.
- Check existing issues before opening a duplicate.
- For substantial changes, open an issue or discussion first so the proposed
  direction can be considered before significant work begins.
- Keep changes focused and explain their purpose.

## Reporting bugs

When reporting a bug, include:

- What you expected to happen.
- What actually happened.
- Steps to reproduce the problem.
- Relevant operating system, browser, and runtime details.
- Any error messages, with secrets and personal information removed.

## Proposing features

Describe the problem the feature would solve, the intended behavior, and any
important trade-offs. Distinguish existing functionality from proposed ideas.

## Pull requests

1. Fork the repository or create a working branch.
2. Make a focused change.
3. Test the change using the project's documented instructions.
4. Update documentation when behavior or setup instructions change.
5. Review your diff and remove unrelated changes.
6. Submit a pull request describing the change, how it was tested, and any
   limitations that remain.

Do not include credentials, private keys, tokens, personal data, or local
runtime databases in commits.

## Review and acceptance

Contributions may be reviewed, requested for revision, or declined to keep the
project coherent and maintainable. Opening a pull request does not guarantee
that a contribution will be accepted or merged.
